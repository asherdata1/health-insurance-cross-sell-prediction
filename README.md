# Health Insurance Cross-Sell Prediction

## Business Problem

Insurance companies invest significant resources in marketing additional products to existing customers. Broad, untargeted marketing campaigns can be expensive and often result in low conversion rates.

The objective of this project is to develop and evaluate supervised machine learning models capable of predicting whether an existing health insurance customer is likely to purchase vehicle insurance. Accurate predictions can help organizations prioritize high-probability customers, improve marketing efficiency, and optimize resource allocation.

## Project Objectives

- Explore and understand the customer data through exploratory data analysis (EDA).
- Prepare the data for supervised machine learning.
- Develop and compare multiple classification models.
- Evaluate model performance using appropriate classification metrics.
- Interpret the business implications of the results and provide recommendations.

## Dataset

The dataset contains over 381,000 customer records from an anonymized insurance provider and was originally released as part of an Analytics Vidhya machine learning competition. Predictor variables include customer demographics, vehicle characteristics, and policy information, while the response variable indicates whether an existing health insurance customer expressed interest in purchasing vehicle insurance.

For this project, we will perform our own train/test split using the labeled training dataset to evaluate model performance.
